# 자유민턴 실시간 운영 완결판 기준

이 문서는 사용자 웹·사용자 APK·관리자 APK·Cloudflare의 복구 및 변경 기준이다. 오류 수정 전 반드시 확인한다. 2026-08-22 `사용자(2).md`를 최우선 기준으로 반영했다. 2026-08-30 관리자 화면 상세 스펙(하단 5버튼, 음소거·볼륨·저장중 잠금 예외, PIN 30일 세션)을 반영했다.

## 운영 아키텍처 절대 원칙

- Google Apps Script는 참고용 코드로만 사용한다. 실행·배포·저장 경로로 사용하지 않는다.
- 사용자 웹과 관리자 웹은 Firebase Hosting의 현재 주소를 유지한다.
- 로그인·조회·배정·경기 종료·자리교환·백업은 Cloudflare Worker에서 처리한다.
- 회원·코트·대기열·게임횟수·설정·백업은 Cloudflare D1에 저장한다.
- 사용자와 관리자의 동시 변경은 Durable Object가 직렬화하여 충돌을 방지한다.
- 사용자 자리 변경을 관리자 자동·수동 배정보다 우선 처리한다.
- 운영 전환 전에 기존 회원 ID, 위치, 게임횟수, 설정을 전수 비교한다. 불일치하면 전환하지 않는다.
- 운영 산출물에 GAS URL, Script ID, Deployment ID 또는 `google.script.run`이 남으면 배포를 실패시킨다.

## 운영 경로

- 사용자 웹: `https://jayuminton-push.web.app/`
- 사용자 APK: Cloudflare push + FCM 네이티브 팝업/진동
- 관리자 APK: Cloudflare 관리자 화면을 APK에 번들하고 네이티브 TTS 사용
- Google Apps Script는 운영 프런트로 사용하거나 신규 배포하지 않는다. 기존 코드 참고만 허용한다.

## 사용자 웹·APK

- 멤버 비밀번호 버전이 바뀌지 않으면 세션을 유지해 자동 로그인한다.
- 본인 미설정 시 이름 검색 또는 카드 1회 선택 후 `취소 / 네, 저예요`로 확정한다.
- 본인 카드는 노란 이중 테두리, 빨강·노랑 별, 작은 `나` 표시를 유지한다.
- 모든 위치에서 이름을 표시하고, 입력된 급수·구력·메모만 작은 글씨로 표시한다. 빈 항목 안내 문구는 만들지 않는다.
- 신규는 `NEW 신규`, 찬조는 `🎁 찬조`로 표시한다.
- 빈 코트·대기1~5를 누르면 선택 표시 후 저장중 차단 화면을 띄우고 본인을 이동한다.
- 다른 회원 카드는 자리교환 확인 후 요청한다. 상대는 수락/거절하며 5분 무응답이면 실패한다.
- 우측 상단 현황 갱신 버튼을 항상 유지한다.
- 대기2→대기1: 본인 ID 대상에게 `대기1순위입니다. 라켓 들고 준비해주세요.` 팝업과 3펄스×8그룹 강진동을 보낸다.
- 대기1→코트: 배정 코트와 기존 대기1 최대 4명 명단을 표시하고 동일 진동을 보낸다.
- 팝업 확인 즉시 진동을 중지한다. 웹 진동은 전경 보조 수단이고 APK 네이티브 알림이 기본이다.

## 관리자 회원·관리 설정

- 관리자 PIN은 원문을 저장하지 않고, 기존 30일 인증 세션을 재사용해 재접속 시 자동 로그인한다.
- 관리자는 기본적으로 사용자용 진동·팝업이 필요 없다. 다만 관리자 앱에 관리자 본인의 회원 본인 설정이 되어 있으면, 그 본인에게 오는 진동·팝업은 관리자 앱에서도 동일하게 뜬다.
- 관리 설정 버튼을 누르면 `함께 경기통계(총 게임횟수·함께 게임한 상대, 접힌 요약 + 펼치면 전체) / 백업 저장(전원 대기 상태로 만든 백업 1개) / 백업복원 / 전체초기화(전 회원 삭제)` 4개가 펼쳐지고, 다시 누르면 닫힌다.
- 관리 설정은 토글 방식이며 경기통계, 백업 1개 저장, 백업복원, 전체초기화를 제공한다.
- 회원관리 토글에는 인원 요약, 등록·수정, 열람 비밀번호, 게임횟수 조정만 둔다.
- 코트배정 제외(도착전·휴식·귀가) 명단과 코트배정 대기 복귀 버튼은 빠른 코트배정 영역에 항상 펼쳐서 표시하며 회원관리 토글에 넣지 않는다.
- 이름 20자, 성별, 급수·구력, 메모, 신규, 찬조를 저장한다. 신규 등록은 코트배정대기로 들어간다.
- 남성은 연한 파랑/굵은 파랑, 여성은 연한 분홍/굵은 빨강이다.
- 관리자 카드에는 게임횟수를 필수 표시한다. 신규는 풀네임, 비신규는 앞 두 글자를 사용한다.
- 빠른배정은 전체/남자/여자 가나다 정렬과 성별 선택 테두리, 재선택 해제를 지원한다.
- 카드 길게 누르기는 배정대기/도착전/휴식/귀가/삭제/취소를 제공한다.

## 코트·대기 운영

- 문 방향에 따라 `4 3 2 1` 또는 `1 2 3 4`로 표시하며 사용자와 관리자 모두 선택할 수 있다.
- 코트별 4명, 대기1~5별 최대 4명을 표시한다.
- 코트 진입 시 게임횟수 +1, 코트 시간 카운트 시작, 가장 오래된 코트를 다음 종료 1순위로 표시한다.
- 코트·대기 제목 두 개 선택은 전체 교환이다. 같은 위치는 1~4명 다중선택, 다른 위치의 같은 수 인원과 교환한다.
- 모든 선택은 다시 눌러 해제한다.
- 하단에는 스크롤과 무관하게 항상 떠 있는 고정 버튼 5개를 `코트배정대기로 / 실행취소 / 수동배정 / 자동배정 / 새로고침` 순으로 유지한다.
- 코트배정대기로: 1명~여러명 선택 후 누르면 그 멤버들을 코트배정대기 상태로 이동한다.
- 실행취소: 직전 저장 동작 하나를 되돌린다.
- 수동배정: 사람 1명~여러명 선택 후 빈자리 1칸만 클릭해도, 클릭한 그 대기조·코트에 선택 인원 전체를 한 번에 배치한다(원자적 1회 요청, 1명씩 순차 요청 금지).
- 자동배정: 빈자리 1~4곳(코트 1~4·대기 1~5 어디든 혼합 가능)을 먼저 클릭해 표시한 뒤 누르면, 클릭한 각 위치에 남4/여4/남2여2를 우선순위로 최대 4명씩 자동 채운다. 기준을 못 채우면 무시하고 남은 인원만큼 최대한 채운다.
- 코트 인원이 0~4명이어도 경기 종료할 수 있다.
- 사용자 이동이 관리자 저장보다 우선하며 관리자는 남은 자리만 채운다.
- 멤버카드 선택은 코트·대기·제외 목록 어디에 있든 다시 누르면 즉시 해제된다.
- 메시지보내기로 여러 명에게 전송하면 대상 사용자 화면에 진동 3펄스×8회와 함께 메시지 팝업이 뜨고, 확인을 누르면 진동이 즉시 멈춘다.

## 경기 종료 알림

- 종료 즉시 기존 대기1을 해당 코트로, 대기2→1, 3→2, 4→3, 5→4로 순환하고 전 화면을 자동 갱신한다.
- 관리자 APK는 `N번 코트가 나왔습니다. [이름/닉네임 최대 4명], N번 코트로 들어가 주세요.`를 기본 최대볼륨·가장 뚜렷한 한국어 여성 음성으로 3회 반복한다. 음성 자체의 크기를 조절하는 버튼도 옆에 둔다.
- 음성 중 음악은 0으로 만들지 않고 6단계 수준으로 낮췄다가 완료·정지·오류 시 원래 볼륨으로 복원한다. 음악을 완전히 죽이거나 최소(1)로 낮추는 동작은 절대 금지한다.
- 멘트 음소거 버튼은 배경 음악이 아니라 경기종료·대기안내 음성 멘트만 즉시 끄는 단일 on/off 토글이며, 다시 누르면 음소거가 해제된다. 음악 볼륨/재생에는 영향을 주지 않는다.
- 1회 재생, 반복재생, 멈춤 버튼을 유지하며, 음성 멘트가 끝난 뒤에도 관리자가 다시 재생·반복하거나 멈출 수 있다.
- 저장중 잠금은 음성 재생·정지·음소거·볼륨 조절에는 적용하지 않는다. 저장중에도 음성 제어는 항상 조작 가능해야 한다.
- Cloudflare는 코트 배정자와 새 대기1의 회원 ID에만 이벤트를 보낸다.
- 사용자 APK는 저장된 본인 ID와 이벤트 대상 ID가 일치할 때만 팝업과 3×8 진동을 실행한다.
- 관리자는 기본적으로 사용자용 팝업·진동을 실행하지 않는다. 다만 관리자 앱에 사용자 본인 ID가 설정되어 있으면 해당 ID 대상 FCM 알림은 관리자 휴대폰에서도 실행한다.

## 변경 보호

- 사용자와 관리자 배포를 분리한다.
- 사용자 앱 토큰은 본인 회원 ID와 원자적으로 연결하고 다른 회원 이벤트는 무시한다.
- Cloudflare Durable Object 매핑을 보존한다.
- 배포 전후 Cloudflare health, 등록/status/event/unregister, APK 패키지·버전·서명, 필수 화면 마커를 자동 검증한다.
- 관리자 화면 CSS/HTML은 요구사항 구현 또는 명시적 승인 없이 재설계하지 않는다.
