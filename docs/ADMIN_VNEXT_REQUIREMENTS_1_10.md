# 관리자 vNext 요구사항 1~10

## 최우선 보호 규칙
현재 정상 운영 중인 사용자 웹/사용자 앱은 동결한다. 관리자 vNext 개발 중 사용자 공개 도메인, Cloudflare Worker/RPC, 사용자 프론트, 사용자 APK 접속 주소 및 배포를 변경/삭제/재배포하지 않는다. 관리자 프론트는 Google Apps Script 웹앱이 아니라 별도의 Cloudflare 관리자 RPC와 별도 Firebase Hosting 채널을 사용한다. 사용자와 관리자는 데이터만 공유하며 HTML/CSS/버튼/기능 흐름/배포 경로를 공유하지 않는다.

## 1. 멤버 등록/수정 및 카드
- 신규 여부 체크박스 추가, 등록과 수정 모두 저장/불러오기.
- 급수/구력 미입력 시 카드에 미입력 안내 문구를 표시하지 않음.
- 신규 체크 멤버는 이름을 두 글자로 자르지 않고 괄호 끝까지 저장된 풀네임 표시.
- 긴 이름은 카드가 자연스럽게 커져도 되며 카드 내부에서 잘리지 않아야 함.
- 급수/구력이 있으면 정상 표시.
- 게임횟수는 항상 표시.
- 코트배정 제외 영역에 게임횟수 -1뿐 아니라 +1 추가. 0 초기화 유지.

## 2. 하단 관리자 고정바
- 실행취소 유지.
- `위치 자동배정` 명칭을 `자동배정`으로 변경.
- 새로고침 버튼 추가, 실제 최신 관리자 상태를 다시 불러오도록 연결.
- 한 줄에 실행취소 / 새로고침 / 자동배정 배치.
- 자동배정은 크게, 새로고침은 자동배정의 약 절반 폭. 모바일에서도 충분한 터치 크기와 한 줄 유지.

## 3. 게임횟수/경기종료/대기 알림
- 게임횟수 +1 시점은 경기 종료가 아니라 멤버가 코트에 진입하는 순간.
- 코트에서 중간 이탈/대기 이동하더라도 자동으로 게임횟수를 되돌리지 않음.
- 코트 인원이 1~4명 어느 경우든 경기 종료 가능.
- 종료 시 `N번 코트가 종료되었습니다` 음성 안내.
- 그 시점 대기1에 있는 인원 수와 무관하게 전원 호명 및 기존 저장 횟수대로 알림/진동.
- 대기2 등이 대기1로 승급될 때 4명 충족 여부와 관계없이 새 대기1 인원 전원에게 알림/진동.
- 음성은 앱에서 가능한 최대 수준을 우선하고, 주변/배경 오디오는 Android에서 허용되는 범위 안에서 약한 배경 수준(요구값 6)으로 낮추는 방향. OS 권한을 무리하게 우회하지 않음.

## 4. 같은 위치 다중선택
- 같은 코트/같은 대기조에서 사람 클릭은 즉시 1:1 교환이 아니라 선택/해제.
- 1명→2명→3명→4명 누적 다중선택 가능.
- 선택된 인원에게 이동/코트배정/대기이동 등 액션을 일괄 적용.
- 선택된 카드 강조 및 선택 인원수 표시.

## 5. 자동배정 반복 최소화
- 같은 사람들과 1~2회 같이 경기하는 것은 허용.
- 가능한 후보가 있는 한 동일 조합의 3회째 반복을 방지.
- 불가피하면 3회 이상 중복 정도가 가장 작은 조합 선택.
- 기존 위치가 0명=4명, 1명=3명, 2명=2명, 3명=1명만 자동으로 채움.
- 기존 멤버를 자동으로 빼지 않음.
- 동반 경기 횟수와 개인 게임횟수/형평성을 고려해 골고루 배정.

## 6. 고정 묶음
- 1단계는 관리자 전용.
- 관리자에서 2명 선택 후 묶음 지정/해제.
- 서버 데이터에 영구 저장하여 새로고침/앱 재실행 후 유지.
- 남복/여복/혼복과 관계없이 묶음 두 명은 자동배정/이동 시 하나의 단위처럼 함께 다님.
- 고정 묶음 두 사람은 3회 반복 제한의 예외. 나머지 자리는 중복 최소화 규칙 적용.
- 카드에 관리자용 묶음 표시.
- 2단계에서 사용자 웹/앱의 묶음 신청 및 관리자 승인 구조로 확장 예정. 현재 사용자 웹/앱에는 아직 적용하지 않음.

## 7. 급수 기반 자동배정
- 급수 입력 있음 = 숙련자 신호, 급수 미입력 = 일반 그룹 신호로 내부 배정에 활용.
- 가능한 경우 숙련자 4명 경기 또는 숙련자2+일반2 구성을 우선 고려.
- 숙련자2+일반2라면 가능하면 각 팀에 숙련자1+일반1 형태로 균형.
- 인원 부족 시 배정을 막지 않고 다른 핵심 규칙을 지키며 최선의 조합 선택.
- 대략 우선순위: 고정 묶음 보호 → 3회 반복 방지 → 게임횟수/대기 형평성 → 급수 균형 → 기타 중복 최소화.

## 8. 추가 사용자 통계
- 승패 대신 `오늘 함께 경기한 사람 수`를 추가 통계로 사용.
- 예: 게임 5회 · 함께 경기 13명.
- 실제 코트 진입/경기 동반 기록을 기반으로 중복 없는 동반자 수 계산.
- 자동배정의 골고루 섞기 품질 확인에도 활용.

## 9. 메모
- 멤버 등록/수정에 짧은 메모 필드 추가.
- 비어 있으면 카드에 표시하지 않음.
- 향후 사용자 화면에도 표시할 공개용 메모 데이터로 저장할 수 있게 구조화.
- 현재 관리자 개발 단계에서는 사용자 웹/앱 화면을 변경하지 않음.

## 10. 찬조 표시
- 멤버 등록/수정에 찬조 체크 추가.
- 관리자 카드에 작은 찬조 마크 표시.
- 신규 여부와 독립적으로 저장.
- 향후 사용자 화면에서도 동일 데이터를 표시할 수 있도록 저장 구조 준비.
- 현재 관리자 개발 단계에서는 사용자 웹/앱 화면을 변경하지 않음.

## 배포 원칙
관리자 변경은 관리자 전용 Cloudflare 배포 워크플로와 검증을 거친다. 사용자 웹/앱 운영 경로에 영향을 주는 변경이 필요해 보이면 즉시 적용하지 않는다. 배포 성공만으로 기능 성공을 선언하지 않고 로그인 후 실제 데이터 조작 검증 전에는 검증 후보본으로 표시한다.
